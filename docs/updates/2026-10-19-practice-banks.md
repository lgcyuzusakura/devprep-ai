# 2026-10-19 专项题库与不重复练习

## 问题与修复

此前默认按细分知识点取题，题目用“尝试次数少的优先”循环选择，没有做完状态。部署机器有 69 个知识点仅含 1–2 道中文题，因此用户很容易在小范围内反复遇到旧题。普通请求日志没有记录完整练习轨迹；对照答题历史，12 次作答只覆盖 7 个题干，其中“记忆与状态”的两道题出现了 5 次作答。

现在“专项题库”把相近内容归并为 20 个导航方向，包括推荐、Java、网络基础、SQL、数据库、操作系统、前端、Agent、提示词工程等。合并只改变选题范围，原题 ID、出处、学习记录继续保留。分类可以交叉，同题只在推荐总数中计算一次，不能把各分类直接相加。

默认题型是中文选择题，可切换问答题或全部题型。新题模式排除所有已经作答的题，包括答错题；做完显示结束，刷新页面也不会重新塞入旧题。需要复习时主动选择“重练已做题”，每轮排除已练过的题。本轮目标完成后提供继续下一轮的入口。每个范围显示可练、已做和剩余数量。题库与首页统计只计算可用于练习的中文题，避免把尚未翻译的题算入可练总数。

新增 `GET /api/practice/banks` 和 `POST /api/practice/queue`。队列支持 `bank`、`knowledge_point_id`、`domain` 三种互斥范围，以及 `question_type`、`mode` 和 `exclude_ids`。题型默认 `single_choice`；`mode` 支持 `new`、`review`。选题响应不包含答案。旧 GET 选题接口保留供学习 Agent 兼容调用。

## 来源核验

2026-10-19 从牛客公开专项分类接口核验：Java 875、网络基础 1,820、SQL 352、数据库 1,160、操作系统 1,619。它们是牛客站内题量，随其内容更新而变化，本项目没有导入这些题目正文。页面保留 [牛客专项练习入口](https://www.nowcoder.com/exam/intelligent)，并明确显示本地真实题量。用户提到的 Agent、提示词工程题量本次未独立核验。

找到 [lydiahallie/javascript-questions](https://github.com/lydiahallie/javascript-questions) 的简体中文版，MIT 许可，提交 `a8b427b9f7f94f1a2965144ba544b475c5f65829`。导入 150 道现成中文单选题及解析，覆盖类型、作用域、对象、异步和运行机制。导入器保留代码、选项、原文解释、署名、许可证、固定提交定位链接及 SHA-256，拒绝含糊的多答案题和缺失解析的条目；不使用翻译模型。

部署机器导入后实测为 3,873 道中文选择题和 7,064 道中文问答题，共 10,937 道可练中文题。数据库另保留 946 道此前尚未翻译的题，不进入中文练习。这些是全部方向的合计，并不代表 Java、Agent 等每个方向都有大量选择题；部分方向当前仍以问答题为主。公开仓库只提交代码、导入器、文档与原创示例，第三方题目和个人数据继续留在本地。

部分方向的实际选择题量：网络基础 549、操作系统 623、数据结构与算法 498、计算机组成 539、前端 153、数据库 113、Java 12、Agent 3。SQL 暂无独立选择题，保留 274 道问答题。考研 408 共 2,124 道选择题，软考 1,566 道；它们与基础方向存在交集。题量不足的方向明确显示实际数字，不把问答题冒充选择题。

## 验证与部署

验证覆盖双题知识点做完后结束、刷新不重复、错题仍需主动重练、同轮排除、中文数量统计、分类合并、408 网络题跨分类归集、默认选择题、题型切换、账号数据隔离，以及桌面和手机页面。完整回归包含 253 项 Java 测试、39 项主浏览器流程、2 项独立账号浏览器流程和 38 项内容导入测试；模型响应使用本地模拟服务，不向真实网关发送请求。

Docker 更新前备份数据库、旧本地题库及旧镜像；更新后核对既有答题、学习会话、简历、岗位与面试记录，并通过公网入口检查登录、分类题量与新队列。模型配置及账号策略沿用当前部署配置。

本次实测：Docker 健康，原有 12 次答题及另外 5 类业务接口数据完整保留。公网登录、20 个分类、新增 150 题和默认选择题接口校验通过。校内代理后新队列约 0.09–0.23 秒，公网样本约 2–10 秒，公网隧道延迟随网络变化。
