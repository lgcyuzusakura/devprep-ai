# 求职工作台更新

日期：2026-10-16。

## 本次交付

用户维护一份通用简历母版，每个岗位提供独立 JD、写作偏好和笔记。生成结果直接返回完整简历、招聘聊天开场白、自我介绍与跟进草稿，支持编辑、复制和下载，用户可以拿材料自行投递。

- 新增 Spring Boot 求职模块、Flyway V10，以及 React「求职工作台」页面。
- 母版可粘贴、导入文件或从已有简历工作区读取；已有工作区不被修改。
- 每次生成记录母版与岗位快照、模型、时间和依据。历史版本保留；手动修改另存新版本。
- 每版独立附件与 Word、Markdown、话术文本、整套 ZIP 导出。修改现岗位名称或 JD 不会改变旧版的导出身份。
- 岗位收藏、搜索、状态筛选、内置招聘入口、自定义入口，以及 Lever/Greenhouse/Ashby 公开招聘页预览与逐条导入。
- Chrome/Edge 浏览器助手可读取当前页面或选中 JD，导入本机草稿，并在用户点击后将确认的话术填入当前空白输入框。
- 记录实际求职进展及使用的材料版本；可携带选中版本的 JD 和简历进入定向模拟面试。
- 未保存草稿的浏览器本地恢复；乐观版本校验防止过期编辑覆盖；生成期间修改 JD 或母版会拒绝保存过期结果。

## 能力边界

仅提交代码、文档和原创测试数据。个人母版、岗位数据、附件、题库正文、网关密钥、本地备份与迁移 ZIP 均不推送 GitHub。迁移包包含本地题库、应用与算法镜像、Jar、源码和配置模板，新电脑解压后配置自己的模型与密钥即可按说明启动；包内创建新的私人数据。
