# 模拟面试更新（2026-10-15）

新增独立模拟面试页面、Spring Boot API、数据库迁移和历史记录。

- 按岗位随机抽题，或根据目标 JD 与简历材料由 GPT 定向组卷。
- 八股与场景、算法、项目深挖三类题型，支持 3–12 道主问题。
- 四维评分、引用回答解释得失，支持最多两轮追问和即时/结束后反馈。
- 算法题提供语言模板，复用 Docker 样例运行；用代码哈希防止旧运行结果用于新代码。
- 复盘总分、分类分数、优势、漏洞、补强计划，以及 Markdown 和打印/PDF 导出。
- 本地草稿、历史恢复、版本冲突保护、无效模型 JSON 检查，未通过校验时保留原场次。
- 沿用 GPT 网关配置，模型请求串行执行并默认间隔 10 秒，不自动调用 DeepSeek。
- 本地题库仅随私人迁移包交付，密钥与个人记录不上传 GitHub。
- 增加可追溯的离线面经目录：公开版含 48 条 MIT 原创演练；私人包可加载固定版本的 0voice 面经抽取结果，保留文件行号、作者、许可证和修改说明，不导入原答案、视频或联系方式。
- 增加独立难度标准和练习场景：无经验/校招基础档、初级进阶档、有经验高阶档；可手动改成基础/进阶/高阶。小厂、中厂、大厂只调整考查侧重，不冒充真实企业标准。
- JD 组卷先按岗位与难度检索本地面经，作为 few-shot/RAG 参考；服务端只接受本次检索结果的引用 ID，界面和复盘导出显示改编来源。

验证：228 项 Java 测试、33 项 Playwright 测试、3 项面经抽取单元测试、前端构建和 Docker 健康检查通过。测试使用本地 fixture，没有调用真实模型。
