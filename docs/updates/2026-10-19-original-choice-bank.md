# 2026-10-19 原创中文选择题补充

用户希望题目接近牛客专项练习的形式：简短明确的题干、四个可比较的选项、容易混淆的知识边界，以及答题后的解释。因此本次为本机题库编写 200 道原创单选题，覆盖知识理解、代码输出和业务场景。

## 编写与核验

这些题目由当前 Codex 任务编写，未复制牛客题目，也未调用外部模型或另一个模型 API。题目来源显示“DevPrep 原创选择题（AI 编写，非牛客原题）”，署名明确没有经过第三方专家审校；本说明页是原创题来源说明，不是牛客原题链接。

逐题检查题干、标准答案与解析，并实际运行 48 项事实核验：Java 15、Go 9、Python 10、JavaScript 4、SQL 10。针对版本或实现敏感的知识，在题干中注明 Java 17、MySQL 8 InnoDB、Python 版本或 CPython 构建等条件。运行样例只验证对应语义，不构成对整套题库的第三方认证。

每题含四个不重复选项，正确答案位置按稳定题号打散，本次 A/B/C/D 分别为 46/49/52/53 题；每题附解释与易错原因。内部基础/进阶标记为 43/157 题，该标记目前不作为练习页的独立难度筛选。全部题干为中文，保留代码、API 名称和技术名词。

## 本地文件与复用

部署机器中的文件：

- 独立题包：`.cache/content/devprep-original-choices.learning.json`。
- 可读题稿与核验脚本：`.cache/content/original-choices/`。
- 运行中的合并题库：`.cache/content/local.learning.zh-CN.json`。

题目正文继续只保存在本地，GitHub 提交合并工具、测试和说明。源码部署者可按学习包结构编写自己的题目，然后运行：

```sh
python scripts/content-import/merge_choices.py --base .cache/content/local.learning.zh-CN.json --choices .cache/content/devprep-original-choices.learning.json --output .cache/content/local.learning.next.json
```

该命令不会下载题包或调用模型；需要先准备这两个输入文件。新增包必须是带中文题干、选项、准确答案、解析与来源署名的单选题。题号相同且内容一致时幂等合并，内容冲突时拒绝覆盖，以保护已有翻译和其他题目。完成后停止 app、备份数据库和旧题库、替换应用加载的文件，再按原配置启动。已有题目 ID 和答题记录继续保留。

新增 4 项合并测试验证旧译文保留、重复导入、ID 冲突和非法选项，完整内容导入测试为 42 项。普通练习离线判分，浏览这些原创题不会触发模型请求。
