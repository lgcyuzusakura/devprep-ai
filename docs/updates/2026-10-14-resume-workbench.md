# Git 更新报告：简历工作区

开发日期：2026-10-14；交付更新：2026-10-15。基于 main 的 `0a33e2a`，新增面向技术求职者的简历工作区；提交记录可在仓库 main 历史中查询。

## 用户可见变化

- 侧栏新增“简历修改”。支持普通编辑、JD 与原简历定向编辑，也可从零填写简历。
- 分析展示具体优势、材料缺口、岗位要求与原文依据，提供追问和可选增强设想；采用后进入补充材料。
- 生成稿附逐条原表达、改写后、修改原因和引用，保存生成时的原始材料快照。
- 局部 AI 扩写：选择或粘贴一段经历，填写要求，查看扩写与成立前提，再替换或追加。不会自动覆盖正文。
- 五种版式：工程标准、一页紧凑、书面叙事、技术项目、极简文字；可调整字体、字号、留白和颜色。
- 章节上移、下移与自定义新增，可将教育、校园经历放在末尾。
- 八份原创虚构示例：Java、Go、前端、Python、AI 应用、Agent、测试开发、运维/云原生。示例明确标注用途与来源，不是实际候选人简历。
- 保存工作稿与历史版本，支持手动编辑、旧版恢复、Word/Markdown 导出及浏览器打印 PDF；自主编写和导出无需密钥。

## 实现与数据

Spring Boot 新增 ResumeController、ResumeService、ResumeRepository、ResumeDocuments，使用 Flyway V7/V8 管理工作稿、版本和版式数据。前端按路由延迟加载工作区与编辑工具。PDFBox 用于本机 PDF 文字提取；DOCX/TXT/Markdown 同样在本机提取。

简历分析、重写和扩写复用既有模型网关，两种协议均可用，没有绑定某个模型。全局模型请求协调器保证同一时间仅有一个请求，默认前次请求完成后间隔 10 秒，覆盖模型发现、问答、聊天和简历功能。不会自动重试或改用其他模型。

生成引用及数值与输入核对；这些检查并不证明材料真实，也不构成完整语义审核。采用的增强与扩写保留核验提示。版本保存采用 revision 检查，防止多个页面静默覆盖。Word 与浏览器输出可能因字体和排版引擎而分页不同；紧凑版式不承诺任意内容都能压成一页。

## 验证结果

- 209 项 Java 测试通过，包含两种编辑流程、材料快照、冲突、无效模型输出、文档提取/导出、独立编写与版式持久化，以及模型串行与间隔限制。
- 前端生产构建通过；原有大型资源块仍有 Vite 体积提示，不影响构建成功。
- 28 条 Chrome/Playwright 浏览器回归通过，覆盖原有学习功能和五条简历流程；检查了桌面、390px 手机截图与打印 PDF。
- 实际配置的 `gpt-6.1-sol` 串行完成一次合成材料分析和一次重写，输出通过校验；临时工作稿已删除。
- Docker app 镜像已重新构建，原本机数据卷保留，服务健康检查通过。迁移包包含最新程序和本地题库，使用公开配置模板与空密钥示例，不包含个人历史数据或原网关密钥。
