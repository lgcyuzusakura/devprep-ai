# 2026-10-16 独立账号更新

多人使用同一学习服务时，原来的入口密码只能限制访问，无法区分个人记录。本次增加应用内登录和独立工作区，管理员继承原有单人数据，朋友分别保存学习记录、笔记、聊天、简历、求职材料、算法提交与模拟面试。浏览器中的未提交草稿也按账号保存。

管理员可以创建最多 20 个账号，并重置朋友密码；每人可以修改自己的密码。朋友首次登录或被重置后需要改密。修改或重置密码会撤销该账号的旧登录。密码存储为带随机盐的 PBKDF2 哈希，会话令牌只保存摘要。

朋友的模型默认固定为 `gpt-6.1-sol`，可通过环境变量调整；管理员保留当前模型。配置编辑、Codex 导入、模型发现与账号管理仅管理员可用，朋友不能读取配置原文、网关 URL 或密钥配置。多人浏览不受单登录限制；实际模型请求继续使用既有全局串行机制及请求间隔。

部署步骤和环境变量见 [独立账号说明](../accounts.md)。默认本机单人模式保持兼容；共享部署必须显式开启账号模式，并提供 HTTPS 入口。凭据、个人数据、下载题库及实际隧道配置均不进入公开代码仓库。
